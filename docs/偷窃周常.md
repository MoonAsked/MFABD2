# 偷窃周常（PC）

适用于 Windows PC 客户端、1280×720 客户区和游戏简体中文。
任务覆盖剧情卡 1–8 的 13 名固定 NPC；每名 NPC 检查三个角色的偷窃技能。
使用前请解锁相应卡带，并准备游戏内的偷窃角色与技能。

## 任务与周记录

- **偷窃周常**按固定名单依次执行，单名失败后继续其他目标。
- **偷窃周常（二次尝试）**使用同一名单和完成记录，可重试未完成目标。
- 两个任务默认不勾选，仅开放给 PC 控制器；推荐 `PC客户端(Cursor)`。
- **跳过本周已完成 NPC**默认开启，每周一北京时间 08:00 刷新。
  关闭后会重新检查 NPC，仍会跳过游戏内已经冷却的角色。

完成判断同时要求目标 NPC 姓名、三个角色的明确冷却、路线完成节点和结束场景。
结束场景确认后才写入周完成记录，关闭交互或结束场景失败不会导致下次被提前跳过。
预览中的金币或成功率不会单独作为成功依据；任何未确认项都会保留为未完成。
记录沿用现有账号同步与存档机制，使用独立的三角色完成键和 `steal_weekly` 周期。

导航仅使用私有 `StealNav_*` 节点和当前 PC 控制器，不修改采集导航状态。
停止任务后不会启动后续路线。暂不支持手游、PlayCover 或未验证的游戏语言。

## 开发验证

在仓库根目录运行：

```sh
python -m unittest discover -s tools -p "test_steal_*.py"
```

这些测试使用模拟任务、识别结果和临时数据，覆盖周跳过、账号绑定、失败继续、
停止响应、三角色冷却、预览核验及同帧缓存失效；不连接游戏，也不读取真实账号存档。
图像识别准确率与完整游戏流程仍需要 PC 实机验证。
